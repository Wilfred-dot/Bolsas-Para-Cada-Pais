# Bolsas de Mestrado — Pesquisa Global

Dashboard Streamlit para explorar bolsas de mestrado identificadas na pesquisa do perfil (nacionalidades moçambicana e filipina, 27 anos, licenciatura em IT, média 14/20, sem experiência profissional).

## Executar

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

A lista é uma consolidação de oportunidades identificadas e deve ser validada contra a chamada oficial vigente. As linhas com prazo "a anunciar" não são incluídas como datas confirmadas.
