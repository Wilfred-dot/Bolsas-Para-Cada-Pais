# Bolsas de Mestrado — Pesquisa Global

Dashboard Streamlit para explorar bolsas de mestrado e oportunidades de investigação avaliadas para o perfil (nacionalidades moçambicana e filipina, 27 anos, licenciatura em IT, média 14/20, sem experiência profissional). Dados revistos em 24 de outubro de 2026.

## Executar

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

A lista consolida bolsas e fellowships identificados; prazos, benefícios e elegibilidade devem ser reconfirmados no edital oficial de cada ciclo. Datas recebidas em avisos sem confirmação oficial ficam assinaladas como não confirmadas. O fellowship CRG exige matrícula universitária atual e não é uma bolsa de grau.
